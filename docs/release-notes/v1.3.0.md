## Taskbar Battery Widget 1.3.0

### What's new
- **Device log** (`%LOCALAPPDATA%\TaskbarBatteryWidget\logs\devices.log`): connections, disconnections, battery changes, charging and low-battery events. Open it from the tray: *Open device log* / *Open logs folder*.
- **App log** (`app.log`): errors and warnings, including uncaught exceptions. Rotating (1 MB x 3).
- **Last known value**: a disconnected device shows its last battery level dimmed, and the card reads "Disconnected - last value 65 % 2 h ago". It survives restarts and never triggers alerts.
- **Keyboard and accessibility**: navigate the pills with Tab/arrow keys, Enter shows the card, the Menu key opens the context menu.

### Fixes
- If the Windows Bluetooth scan hangs, 2.4 GHz receivers are still read.
- Two controllers of the same model are shown separately.
- Bluetooth Classic + LE devices keep a stable identifier.
- The context menu closes when clicking outside; the card no longer flickers every 30 s; startup no longer freezes the window.
- "Start with Windows" respects being disabled from Task Manager, and the installer no longer re-enables it on update.
- Several robustness improvements in HID reading, Logitech, Razer and alerts.

### Privacy
Logs do not store MAC addresses, device paths or the Windows user name.

### Downloads
- **TaskbarBatteryWidget-Setup-1.3.0.exe** - installer (updates previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.3.0.exe** - single executable, no installation.
- **SHA256SUMS.txt** - checksums for both files.

The executables are not code-signed: if Windows SmartScreen warns, click **More info -> Run anyway**.
