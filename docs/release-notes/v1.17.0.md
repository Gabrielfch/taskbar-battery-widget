## Taskbar Battery Widget 1.17.0

### Fixed
- **Hidden over browser fullscreen.** With *Visible in fullscreen* off, the widget now also hides over a
  browser in fullscreen (a video's fullscreen button or F11). Windows doesn't report these as fullscreen, so
  the widget stayed visible (#9).
- **Several monitors:** the widget stays hidden over a fullscreen window on its monitor even after you click
  on another monitor. Before, it came back after a few seconds (#9).

### Changed
- *Settings ▸ Personalization ▸ Position* only shows the options that apply: *Floating position* appears when
  the position is *Floating*, and *In fullscreen* (where to show it over a fullscreen app) appears once
  *Visible in fullscreen* is on.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.17.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.17.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
