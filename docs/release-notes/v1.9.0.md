## Taskbar Battery Widget 1.9.0

### New
- **Settings inside the panel.** The gear button turns the device panel into a navigable settings view: a back
  arrow returns to the previous page, pages open with a chevron, check boxes toggle in place and choice lists
  unfold below and stay open while you try options.
- **Personalization.** Colour palettes (classic, colour-blind friendly, pastel, high contrast, mono, or your
  own colours with automatic contrast correction) and device icon styles (outline, filled, simple, retro pixel
  art, battery, none).
- **Custom icons.** Use your own image (PNG, JPG, BMP, ICO, GIF or SVG) for every device of a type or for one
  device. `docs/ICON_PROMPT.md` has ready-made prompts to create one with an AI chat.
- **Aliases.** The pencil on a device row renames it; while editing, click the device icon to change it or the
  × to go back to the default. Logs and statistics keep their history.
- **Panel size and interface scale.** The panel keeps one size (compact, normal or large, proportional to the
  screen) and scrolls when needed; the interface scale (90–130 %) also resizes the taskbar pills.
- **7 languages.** English, Spanish, Portuguese, French, Russian, Simplified Chinese and Japanese, selectable in
  *Personalization ▸ Language*. The new translations are machine-made — corrections are welcome (see the
  README).
- **What's new and tutorial.** *About* shows a new version's notes before you install it, the app shows what
  changed once after an update, and a short tutorial opens on first run (also in *Settings ▸ Tutorial*).

### Fixed
- File and colour pickers opened from the panel no longer close by themselves.

### Security
- Imported SVG icons are checked against an allow-list of basic shapes, rebuilt and converted to PNG; scripts,
  external references, styles, filters and embedded images are rejected.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.9.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.9.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
