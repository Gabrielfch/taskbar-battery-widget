## Taskbar Battery Widget 1.12.0

### New
- **Pill styles.** *Settings ▸ Personalization ▸ Pill style*: Classic, Soft, Transparent (new default) or
  Transparent compact. Without a background, a low battery shows as a red value with "!", and text colours
  are adjusted to stay readable on light and dark taskbars.
- **Stack devices.** *Settings ▸ Personalization ▸ Position ▸ Stack devices*: while the widget floats, one
  device per row in a column, with the values aligned. On the taskbar the pills stay in a row.

### Fixed
- Razer mouse mats (Firefly, Goliathus…) no longer appear as a mouse at 0 %.
- The debug log shows more detail about Razer devices that cannot be read yet.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.12.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.12.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
