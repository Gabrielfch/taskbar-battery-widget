## Taskbar Battery Widget 1.5.0

### What's new
- **Device panel** (left or right click on the tray icon, or right click on the taskbar pills): a scrollable list
  with **Connected** (green) and **Known** devices, each row coloured by its state (level, charging, idle,
  unknown, last known value). An **eye** per device shows or hides it on the taskbar; the eye on the *Known*
  header shows or hides disconnected devices. Shows *Bluetooth is off* when the radio is off.
- **Icon toolbar** at the bottom of the panel: Refresh, Show all in the taskbar, Settings, About, Quit. Every
  button has a short tooltip; the screen reader gets the full description.
- **Settings menu** (gear button): *Sources*, *Alerts*, *Logs*, *Start with Windows*, *Personalization*.
- **Simpler sources**: only **2.4 GHz and USB** and **Bluetooth**, both on. A source that is off means its
  devices are not queried at all.
- **Per-device detailed log** (optional, off by default): the record button on a panel row writes one CSV row
  per minute (time, battery, charging, connected, link, idle, stale) to
  `%LOCALAPPDATA%\TaskbarBatteryWidget\logs\devices\`. The first row is written as soon as recording starts;
  files rotate at 1 MB (max 4 MB per device) and are deleted after 90 days. The *…* button opens the folder.
  Also in *Settings ▸ Logs*.

### Changed
- The *Experimental readers* option is gone: readers that used to be experimental are now **on by default**
  (XInput, Logitech G533/G633/G933/G PRO and Astro A50 Gen 5, Jabra, Audeze, Lenovo, MCHOSE, most SteelSeries
  and Corsair headsets, HyperX Cloud II (HP) and Cloud Alpha 2, DualShock 4 over USB, PULSE 3D, INZONE).
  Most of them are implemented from public protocol notes and **have not been tested on real hardware**.
- A small **beta** set stays off unless `"beta_readers": true` is set in
  `%APPDATA%\TaskbarBatteryWidget\config.json`: Logitech PRO X 2 / PRO X 3 / G522, Corsair Void V2 /
  Virtuoso Max / HS80 Max, HyperX Cloud Alpha Wireless and Cloud II Wireless (Kingston), SteelSeries Arctis 1 /
  7 / 9, Arctis Pro Wireless, Arctis Nova Pro Wireless, DualShock 4 over Bluetooth. If you had experimental
  readers enabled, beta readers stay enabled for you.
- The tray menu and its *Show* submenu are replaced by the device panel.

### Update
- From 1.4.0: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the Setup below.
- Settings are kept and migrated automatically.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.5.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.5.0.exe** — single executable, no installation.

The executables are not Authenticode-signed: if Windows SmartScreen warns, choose **More info → Run anyway**.
