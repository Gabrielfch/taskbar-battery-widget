## Taskbar Battery Widget 1.7.1

### Fixed
- **Razer Basilisk V3 Pro** (1532:00AA wired, 1532:00AB wireless) and other newer Razer devices that answer the
  battery query on their mouse/keyboard collection were not shown
  ([#1](https://github.com/Gabrielfch/taskbar-battery-widget/issues/1)). Razer collections are now opened with
  query-only access (feature reports), and the mouse/keyboard collection is tried when it declares the 90-byte
  feature report. Still only the read-only battery and charging queries are sent. The wired/wireless link is
  taken from the device table. Not yet confirmed on real hardware — feedback welcome in #1.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.7.1.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.7.1.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
