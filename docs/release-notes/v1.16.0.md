## Taskbar Battery Widget 1.16.0

### New
- **SteelSeries Rival 3 Wireless** mouse (2.4 GHz dongle `1038:1830`). **Beta reader, off by default**:
  enable it by adding `"beta_readers": true` to `%APPDATA%\TaskbarBatteryWidget\config.json`. It only sends
  the mouse's battery query and shows the level; the mouse runs on replaceable batteries, so it never shows
  as charging. The first reply is written to `app.log` (*About… ▸ Open logs folder*) to help confirm the
  format. Thanks to Leandro Paixão for the contribution.

### Fixed
- Areson 2.4 GHz mice (beta): a dual-mode mouse such as the Gamspeed V8 Pro no longer shows up twice while its
  cable is plugged in. The dongle entry is kept and takes the level and charging state from the cable (#9).

### Changed
- README: Astro A50 Gen 5 is now listed as verified on real hardware (#9).

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.16.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.16.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
