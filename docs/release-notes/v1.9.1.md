## Taskbar Battery Widget 1.9.1

### Fixed
- A device that does not report charging (for example an Xbox Wireless Controller over Bluetooth) could show
  "Charging" right after reconnecting and keep it for up to 30 minutes. Windows first reports a placeholder
  level and the real one a few seconds later; that jump is no longer taken as charging. Rises during the first
  2 minutes of a connection, or of more than 10 points within a minute, now only update the reference level.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.9.1.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.9.1.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
