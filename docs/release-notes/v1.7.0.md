## Taskbar Battery Widget 1.7.0

### What's new
- **Fullscreen overlay that stays out of the way**: with *Visible in fullscreen* on, while a game or app is in
  fullscreen on that monitor the widget lets clicks pass through to it and shows no hover card. Hold **Shift**
  to use the widget normally (click, hover card, right-click panel, drag); release Shift and it goes back to
  pass-through. Everything returns to normal when fullscreen ends.

### Changed
- If Windows **Smart App Control** blocks the downloaded installer (it is not Authenticode-signed), the *About*
  window now says so and the app keeps running, instead of a generic "could not start the installer".
- More robust handling of monitors that disappear while the widget reads them (unplug, remote desktop).

### Known limitations
- The executables are not Authenticode-signed. On PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.
- Pass-through works over borderless/windowed fullscreen, not over exclusive DirectX fullscreen. Holding Shift
  in a game that uses it (e.g. to run) also makes the widget clickable while it is held.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.7.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.7.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
