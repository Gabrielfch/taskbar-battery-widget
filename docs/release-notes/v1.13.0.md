## Taskbar Battery Widget 1.13.0

### New
- **Your own device order.** Drag a device in the panel (within *Connected* or *Known*), use Alt+Up/Down, or
  right-click ▸ *Move up* / *Move down*. The taskbar follows the same order; hiding, showing, connecting or
  disconnecting a device no longer reshuffles the rest.
- **Razer BlackShark V2 Pro (2023) over its 2.4 GHz dongle** (1532:0555). Read-only queries only, so the dongle
  must have been initialised by Razer Synapse in the current USB session; over Bluetooth it works as before.
- **AULA F108 Pro** keyboard over its 2.4 GHz dongle (05AC:024F, "F108Pro Dongle").
- **8BitDo controllers:** Ultimate 2 2.4 GHz dongle and Ultimate 2 / Ultimate 3 over USB. SF30 Pro, SN30 Pro,
  Pro 2 and Pro 3 over USB are beta readers (off by default). The Ultimate 2C reports its battery only over
  Bluetooth.
- Logitech G502 X PLUS verified on real hardware.

Thanks to @Lucrilhas for the BlackShark, AULA and 8BitDo readers, all tested on real hardware.

### Changed
- Pill corners now match the Hardware Monitor widget: small corners for every style except Classic.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.13.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.13.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
