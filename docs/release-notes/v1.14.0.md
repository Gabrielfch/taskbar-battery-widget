## Taskbar Battery Widget 1.14.0

### New
- **Keyboards on a Compx 2.4 GHz receiver** (`3554:FA09`), such as the AULA F75 (verified) and probably
  other brands using the same receiver (e.g. Redragon K618, untested). The reader only listens: the keyboard
  sends its level when it changes, when the cable is plugged in or out and when it returns to 2.4 GHz mode.
  A level remembered from an earlier session is shown as the last value until a fresh one arrives.
  Charging is not reported yet.
- **HyperX Cloud Flight 2 Wireless** (`03F0:0AC1`).
- **Razer BlackShark V2 Pro (2023) without Synapse** (optional). *Settings ▸ Sources ▸ Activate Razer
  dongles without Synapse* (off by default) sends Razer's own activation command to the 2.4 GHz dongle when
  it doesn't answer. It is the same command Synapse sends, at most once per plug-in, and it is reported to
  reset when the dongle is unplugged. This is the only command the app can send that is not a plain
  query; it is documented in the reader contract. If the dongle doesn't answer and the option is off, the
  app shows a one-time notice pointing to it.

Thanks to @Slackpartistic for the Compx and HyperX readers, tested on real hardware.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.14.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.14.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
