## Taskbar Battery Widget 1.4.0

### What's new
- **About window** (tray menu → *About Taskbar Battery Widget…*): version, license, links to the project, releases, third-party notices and device reports, logs folder, and copyable technical info for bug reports.
- **Update check**: *Check for updates* in the About window, plus an optional daily automatic check (**off by default**). The app only contacts `api.github.com` / `github.com` for this repository and sends nothing but a standard HTTPS request with its version in the User-Agent.
- **Signed self-update** (installed copies): *Download and install* fetches the Setup from this repository's release and installs it only if `SHA256SUMS.txt` carries a valid **Ed25519 signature** from the maintainer key embedded in the app and the installer matches its hash. Two confirmations are asked; the app restarts after a silent install. Portable and source copies just open the release page.

> This is the first version with the updater: to get it, install 1.4.0 manually. Later versions can be installed from the app.

### Release process
- Releases are built and tested by GitHub Actions (read-only build job, write-scoped publish job, build provenance attestations) and published as drafts; the maintainer verifies provenance and hashes and signs `SHA256SUMS.txt` locally before publishing.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.4.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.4.0.exe** — single executable, no installation.

The executables are not Authenticode-signed: if Windows SmartScreen warns, choose **More info → Run anyway**.
