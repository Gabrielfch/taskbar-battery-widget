## Taskbar Battery Widget 1.11.0

### New
- **App theme.** *Settings ▸ Personalization ▸ Theme*: Automatic (follow Windows, default), Light or Dark. It
  applies right away to the device panel, its settings pages and the app windows (About, statistics,
  tutorial). Pills on the taskbar keep following the taskbar; floating pills use the chosen theme.
- **Sun/moon button** at the top of the device panel switches between light and dark in one click.
- **Personalization button** (palette icon) in the panel's bottom toolbar opens *Personalization* directly.

### Other
- New screenshots and animations in the README.

### Update
- From 1.4.0 or later: *About… ▸ Check for updates ▸ Download and install* (signed update), or install the
  Setup below. Settings are kept.
- The executables are not Authenticode-signed: on PCs with Smart App Control turned on, Windows blocks them,
  including in-app updates.

### Verify your download
- `SHA256SUMS.txt` lists the SHA-256 of both executables; `SHA256SUMS.txt.sig` is its Ed25519 signature (see
  SECURITY.md for the public keys and manual verification).
- `gh attestation verify <file>.exe --repo Gabrielfch/taskbar-battery-widget` checks that the file was built by
  this repository's workflow.

### Downloads
- **TaskbarBatteryWidget-Setup-1.11.0.exe** — installer (upgrades previous versions and keeps your settings).
- **TaskbarBatteryWidget-portable-1.11.0.exe** — single executable, no installation.

If Windows SmartScreen warns, choose **More info → Run anyway**.
